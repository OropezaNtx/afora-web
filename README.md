# ALURA Web

Landing oficial de ALURA, plataforma de operaciones de campo.

## Stack

- React
- Vite
- Lucide React
- CSS propio

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run preview
```

## Rama de trabajo

La primera versión visual se desarrolla en:

```text
feat/landing-v1
```

## Dirección visual

La landing prioriza:

- estética oscura y precisa;
- escenas grandes de producto;
- narrativa mediante scroll;
- animaciones relacionadas con GPS, recorridos y sincronización;
- pocas cards y más presencia visual;
- interfaces de ALURA como protagonista.

## Recursos visuales

Las rutas de imágenes están centralizadas en:

```text
src/config/assets.js
```

La estructura recomendada para sustituir recursos se encuentra en:

```text
public/images/README.md
```
